# 陳恩英文的教室札記

每個月底寫給家長的一封信。網站是純靜態網頁，放在 GitHub Pages 上，不需要另外的主機或資料庫。

## 網址一覽

假設網站開在 `https://drickchen.github.io/iansnewsletter/`：

| 頁面 | 網址 | 給誰看 |
| --- | --- | --- |
| 首頁（六個班的入口） | `/` | 任何人 |
| 週一班～週六班 | `/monday/`、`/tuesday/`、`/wednesday/`、`/thursday/`、`/friday/`、`/saturday/` | 各班家長 |
| 寫信桌（後台） | `/admin.html` | 老師 |
| 示範信 | `/demo/` | 老師自己參考 |

每一班的頁面只會看到自己班的信，最新的一封會裝在信封裡，下方有「往期札記」可以翻回之前的月份。

## 第一次上線

1. 到儲存庫的 **Settings → Pages**，Source 選 **Deploy from a branch**，選擇放著這些檔案的分支、資料夾選 `/ (root)`，按 Save。
2. 大約一兩分鐘後，頁面上方會出現網站網址。
3. 打開 `admin.html`，按右上角「連線設定」，依照視窗裡的步驟建立 Fine-grained token（只勾選這個儲存庫，Contents 設為 Read and write），貼上後按「儲存並連線」。分支欄位請填 Pages 使用的那個分支（留白會自動用儲存庫的預設分支）。

## 每個月寫信

1. 打開 `admin.html`，在上方選班級。
2. 填月份、標題，寫內文。右邊（手機上是「預覽」分頁）會即時看到信紙的樣子。
3. 想看完整的拆信動畫，按「在信封裡預覽」。
4. 按「發佈給家長」，網站大約一到兩分鐘後更新。
5. 按「複製家長連結」，貼到班級群組。

寫到一半關掉也沒關係，草稿會自動存在這台裝置上。點左側列表裡已發佈的信，可以修改或刪除。

### 內文排版

- 每一行就是一個段落
- `## 小標題`
- `**重點**`：粗體加淡淡的螢光筆
- `> 引言`：適合放孩子在課堂上說的話
- `- 條列`、`1. 編號`
- `---`：分隔
- 照片：按工具列的「照片」，會自動縮小、上傳並插入

## 檔案結構

```
index.html          首頁
monday/ … saturday/ 六個班級頁
demo/               示範信
admin.html          寫信桌
assets/             樣式與程式（班級名稱與顏色在 assets/common.js 最上方）
data/<班級>.json     各班的信件內容
images/<班級>/       信裡的照片
```
