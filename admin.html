    連線設定

    寫信桌透過 GitHub 直接把信放上網站。第一次使用時，請建立一把只能修改這個網站的「鑰匙」（Token），貼在下面，之後就不用再設定了。

    1. 打開 GitHub 建立 Fine-grained token 的頁面。
    2. Token name 隨意取，例如「教室札記」；Expiration 可以選一年。
    3. Repository access 選 Only select repositories，勾選 iansnewsletter。
    4. Permissions 裡找到 Contents，設為 Read and write。
    5. 按下 Generate token，把那串以 github_pat_ 開頭的文字複製貼到這裡。

    Token 只會存在這台裝置的瀏覽器裡，不會出現在網站上。換手機或電腦寫信時，需要再貼一次。
